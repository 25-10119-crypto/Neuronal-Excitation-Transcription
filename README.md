# Neuronal Excitation–Transcription Coupling

교육용 단일 페이지 인터랙티브 시뮬레이터입니다. `index.html`을 브라우저에서 열면 별도 라이브러리나 서버 없이 실행됩니다.

## 포함 기능
- 신경세포 모식도에서 시냅스 → 수상돌기 → 세포체 → 핵의 흐름 시각화
- Ca²⁺ 최고 농도, burst 길이·간격, K⁺ 통로 기능에 따른 활동전위 폭의 단순화된 변화, CaMKIV·ERK/MAPK 경로 기여도, CREB 감쇠 반감기 조절
- 30분 시간축에서 Ca²⁺, 경로별 활성, 합산 pCREB 변화 표시
- 두 실험 조건(짧고 잦은 burst / 길고 드문 burst) 빠른 비교
- 논문 수치와 교육용 모델 가정의 구분 및 참고문헌 링크

## GitHub Copilot에 추가 개선을 요청할 프롬프트
현재 `index.html`을 읽고 기존의 단일 파일 구조를 유지하면서 다음을 개선해줘.
1. 시뮬레이션의 각 변수와 수식에 주석을 추가하고, 실험에서 직접 측정한 값과 교육용 모델 가정을 화면에서 구분해줘.
2. CaMKIV와 ERK/MAPK 경로의 시간적 차이를 더 분명하게 애니메이션으로 나타내고, 경로별 기여도를 끄거나 켤 수 있는 체크박스를 추가해줘.
3. 1.8초/1분, 9초/5분 두 자극 조건의 결과를 나란히 비교하는 그래프를 추가해줘.
4. c-FOS 지수를 실제 mRNA fold-change로 오해하지 않도록 모든 화면에서 '상대 모델 지수'라고 표시해줘.
5. 모바일 화면에서도 SVG와 그래프가 겹치지 않도록 반응형 레이아웃을 점검해줘.

## 수치·출처 해석 주의
- Fields et al. (1997)의 DRG 배양 실험은 10 Hz, 1.8초/1분 및 9초/5분 조건을 사용해 30분간 총 540개의 활동전위를 비교했습니다. 이 실험에서 칼슘 peak와 c-FOS 반응은 단순한 농도 크기만으로 설명되지 않았습니다.
- CaMKIV의 빠른 CREB 활성화 및 ERK/MAPK의 지연성 신호는 서로 다른 시간 특성을 갖습니다.
- 화면의 경로 활성도와 c-FOS 수치는 여러 생물학적 과정을 단순화한 교육용 상대 지수이며, 실험 데이터에 대한 정량 예측 또는 특정 개별 세포의 진단 결과가 아닙니다.
